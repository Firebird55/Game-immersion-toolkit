Prepare the languages you choose

  1. Download the latest Windows release, extract it and open Install.cmd. Select your installed game folders.
  2. For voiced games, install the original voice pack for the language you are learning. In Setup → game → Languages, explicitly prepare that learning language and the required official translation table. Hito uses its existing Chinese/English text catalog without a voice pack.
  3. Connect your Lexirise account if desired. The Windows account switcher keeps named credentials protected with Windows DPAPI. Translation language, dictionaries, inline glosses and reading options follow each learning language's settings. The global translation target is used only when that language has no target.
  4. Choose matching spoken audio in the game and calibrate capture. For example, Dutch learning with Chinese translation is supported in BEYOND and HEAVY RAIN; Chinese subtitles can match the prepared official table.

Opening settings or adding an account does not prepare every language or create dictionaries. Prepare new translation tables explicitly. Updates refresh only languages already prepared. Word lookups happen when you request them.

Missing official translations stay unavailable. There is no generated translation or English substitution. Original game assets stay on your PC and are never included in downloads.

Independent mobile OCR

Open a privately exported catalog and optional voice ZIPs. Recognition currently covers English, Simplified Chinese and Traditional Chinese subtitles, including English/Chinese combinations. It does not recognize every learning language listed above. The PC can be off after export.

Lexirise reading aids, inline glosses and lookups use the learning language's preferences. Dictionary setup is explicit. Migaku remains an independent mode and requires a compatible browser extension. Browser screen capture can be unavailable on iPad or stop in the background; the native iPad capture helper is not included.

What “supported” means

Storefront language lists describe the game. Toolkit tables describe implemented readers; they do not promise every subtitle is captured. Unverified locales are labelled separately. Missing packs, ambiguous performances and untranslated lines remain unavailable.

Asset decoding, synthetic OCR, recorded gameplay and mobile checks are different evidence. Resized footage is not native-resolution testing, and browser display scaling is not physical Windows DPI testing. Full chapter and branch coverage remains incomplete. Uncaptioned speech is outside capture coverage.

Cyberpunk and Witcher retain supported dual-language subtitle mods, including wrapped and same-writing-system pairs. A mod is optional.

Honkai Impact 3rd is archived and unsupported. It is excluded from supported-game lists and setup.
