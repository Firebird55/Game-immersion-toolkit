Modification by the Game immersion toolkit project, 2026-10-31:
cmake-compilerid-instance-location.patch derives a local directory by removing only a trailing four-component version field. The complete instance must still equal that directory plus the version reported by CMAKE_VS_VERSION_BUILD_NUMBER, or configuration fails. Only the two CompilerId auxiliary property-path constructions use this local directory, which is then unset. The global instance identity, generator, exact toolset and SDK flags, executable and every other supplier file remain unchanged.

This is a separately identified, private ASR build-host source-module adaptation, not an upstream CMake release. The shared official tool and FFmpeg build do not use it.
