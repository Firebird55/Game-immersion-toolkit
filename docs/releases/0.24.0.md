# Game Immersion Toolkit 0.24.0

This Windows and Android prerelease adds independent publisher preparation for Global Zenless Zone Zero on Android. Choose Text only or Text + audio in Settings, then use a VDO.Ninja viewer link to capture subtitles and play downloaded original recordings. The signed APK has been installed in place on physical ARM64. Owner gameplay validation is pending. The other Android game integrations will follow separately.

On Windows and Android, a confirmed Belle or Wise line can select the correct original movie audio for ambiguous subtitles, including the five early captions in `C055_EP020`. A new capture can fall back to the previous confirmation for the same account and prepared source. Context recordings retain their original branch and selected dub.

Download the installer or APK together with SHA256SUMS. The release receipts identify the exact source and binary hashes.
