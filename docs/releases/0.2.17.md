# 0.2.17 — Mobile libraries from Files

The mobile companion can read a privately exported game catalog and original
Mandarin voices selected from **Files → On My iPhone**. The PC prepares the
library and can be off during receiver use. GitHub Pages hosts the application
and licensed OCR runtime; users supply their own game files.

Desktop **Setup → Games → Export mobile library** and the matching CLI export
catalogs and MP3 voice ZIPs capped at 512 MiB. Exports preserve verified voice
bindings, variants, speakers and authored anchors, reuse completed work, and
publish atomically after source checks. Refresh and export again after a game
update. Existing adapter and DLC coverage applies; export does not verify new
chapters or previously unsupported scenes.

The phone reads individual ZIP entries, caches text/history/calibration in
IndexedDB, and requests voice-pack reselection after reopening. It runs pinned,
self-hosted English/Chinese Tesseract.js 7 OCR, displays catalog-backed bilingual
transcripts, and provides manual original-voice playback, favorites, crop
calibration and private test reports. Direct reconnect and application updates
retain user data.

Automated package, exporter, browser OCR/playback, reconnect and update checks
pass. Synthetic layout checks cover 64 cases; the private footage replay passes
35 of 54 annotated cases, with remaining small/wrapped caption misses reported
in the page. Physical iPhone reliability remains unverified. Windows WebKit
cannot run the media fixture; full WebKit media verification passes on Linux CI,
including local playback and warmed Chinese OCR after an offline reload.

See [transfer and iPhone testing](../mobile-library.md) and
[verification boundaries](../mobile-library-verification.md). A working mobile
system-capture sender remains necessary for foreground iPad gaming; a native
capture helper is outside this release. Existing desktop reading features remain
available.
