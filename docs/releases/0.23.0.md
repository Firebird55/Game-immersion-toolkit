# Game Immersion Toolkit 0.23.0

## Read the subtitle that is on screen

Authored subtitle pages now stay separate instead of expanding into an entire
conversation. This fixes the reported BEYOND: Two Souls paragraphs and preserves
page boundaries in Heavy Rain, Detroit, Rise of the Tomb Raider, Spyro, Source
games and Ground Zeroes. The shared rule applies across supported readers; the
[boundary audit](../subtitle-boundary-audit.md) records each format and its limits.
Visual line wrapping is not treated as a new subtitle page.

When the game supplies exact recording intervals, playback uses the individual
excerpt. Otherwise the original recording is labeled **Play full paragraph**.
Sentence export omits that longer recording when page timing is unknown, while
retaining the line's voiced status. Translation pages are attached only when
their alignment is established; a missing translation does not substitute a
different language or guess a page from its position.

Delayed visibility reports and audio preparation no longer move the current
reader back to an older confirmed subtitle. Mixed Traditional/Simplified Chinese
matching also preserves meaningful character distinctions, fixing reported
short-line misses.

## More room for dialogue

Current and earlier lines use the same text size in a connected reading area.
The compact Favorites/History toggle replaces the separate tab bar, and game-data
update progress does not insert a panel above the current line. Phone and tablet
layouts use the same Web UI with narrower margins and compact controls.

Shared reading components 1.0.14 improve annotated Latin text: words share a
baseline, glosses have bounded widths, and punctuation and apostrophes stay with
their source words. Chinese annotations and the independent Migaku mode remain
available. The fixes are shared with the Lexirise userscript consumer.

## Capture and desktop delivery

- ZZZ has persistent Automatic/Belle/Wise selection across caption channels.
  Automatic inference uses relevant scene evidence; a manual selection wins.
  Menu rejection and top-right dialogue capture have additional regressions.
- Capture follows the game window and its monitor, retaining calibration across
  display movement and resize. Native capture runs in an owned child so its
  failure can be reported and recovered without terminating the transcript API.
- Native desktop packages include their application runtimes and supported
  helpers. The executable opens the transcript browser and provides a visible
  status/log window plus tray actions. Windows Setup offers a changeable Program
  Files destination and separate Start menu/Desktop shortcut choices.
- Phones and tablets can open the desktop's local-network address and port, or
  connect through the mobile player's desktop connection flow.

Native release targets are Windows x64, Linux x64 and Apple silicon macOS 14 or
later. Packages are unsigned; macOS notarization and Intel Mac support are not
claimed. Operating-system capture permissions and Linux display-server support
remain distinct from package construction. See the
[native acceptance record](../desktop-native-acceptance-plan.md) for exact checks
and remaining physical-device limitations.

## Verification and scope

GitHub Actions checks source publication safety, application behavior, browser
groups and native packages. Native artifacts require exact dependency/source
review and frozen-process acceptance before publication. Checksums and provenance
accompany published artifacts; game files, original recordings, account data and
private session photographs are never bundled.

The supplied game screenshots have capture regression coverage for seven games.
The [regression plan](../capture-regression-completion-plan.md) keeps missing
fixtures for other games explicit. Synthetic and file-format checks do not
establish complete gameplay coverage for every scene, language, monitor or device.
The [live-session follow-up](../live-session-follow-up.md) distinguishes the
reported examples verified against installed resources from pending live capture.
