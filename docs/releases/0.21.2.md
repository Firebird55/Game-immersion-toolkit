# Game immersion toolkit 0.21.2

This update clarifies language preparation and fixes another ZZZ catalog layout
found while checking installed game files.

- Fixed a startup failure after preparing ZZZ. The selected multilingual index
  no longer receives legacy TextMap-only calls during startup or an update
  handoff. An in-flight legacy refresh also keeps its original index if the
  selected language changes.

- ZZZ resource catalogs now respect Unity's alignment padding after block
  records. Both the base catalog and the current update catalog are supported;
  regression fixtures cover all four alignment cases and reject corrupt padding.
  Existing ZZZ tables refresh once to use the updated reader.
- Language setup distinguishes a failed status request from a failed preparation.
  Connection and HTTP errors retain the last known status, retry automatically,
  and provide a Retry status button. A successful status refresh no longer hides
  an actual failed preparation action.
- A language that has not been chosen is no longer labelled as a missing voice
  pack. The setup card directs users to the per-language inventory and preparation
  controls. Per-game update details explicitly distinguish Ready, Preparing and
  Preparation failed.
- File-access errors mention toolkit storage as well as game files. Permission
  failures are identified separately without exposing private paths.
- Unresolved ZZZ metadata references are reported as coverage notes. They do not
  invalidate verified dialogue or prove a voice pack is missing. The current
  installed-data audit still has 333 unresolved scene references; no recording
  bindings have been guessed or silently classified as unvoiced.

This release retains the 0.21.1 installed-runtime catalog fix and resilient
progress-file writes. Regression sources are checked into the repository and
run in GitHub CI; local runs are limited to focused checks and installed-file
acceptance that hosted runners cannot perform.
