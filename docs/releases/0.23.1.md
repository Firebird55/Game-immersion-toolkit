# Game Immersion Toolkit 0.23.1

This delivery includes the connected transcript reader, capture reliability fixes
and native Windows, Linux and macOS packages described in the
[0.23 feature notes](0.23.0.md).

- Show authored subtitle pages individually instead of expanding a short
  on-screen subtitle into a full paragraph. Delayed results cannot rewind the
  newest confirmed line, and mixed Chinese-script matching catches reported
  short-line misses.
- Give current and earlier lines equal text size, compact controls and connected
  reading space. Improve annotated Latin spacing and punctuation. Use the same
  Web UI on phones/tablets and connect to the desktop over the local network.
- Preserve ZZZ Automatic/Belle/Wise selection, improve menu/top-right capture,
  follow the game monitor and recover owned capture workers after failure.
- Start through an executable with visible status/logs, tray actions and automatic
  browser opening. Windows Setup offers Program Files by default, a changeable
  destination, and independent Start menu/Desktop shortcut choices. Application
  runtimes and supported helpers are bundled.

The 0.23.0 tag was not published because its Windows build detected metadata
rewritten during release preparation. Preparation now preserves already-correct
files, while retaining strict source-integrity checks. The
[investigation](../native-release-metadata-2026-11-01.md) distinguishes diagnostic
results from release acceptance.

Native targets are Windows x64, Linux x64 and Apple silicon macOS 14 or later.
Packages are unsigned. Physical-device, operating-system capture permissions,
unsupported formats and missing screenshot fixtures remain explicitly documented;
these checks do not claim every game scene, voice pack or device was exercised.
Checksums and provenance accompany published artifacts. Game files, original
recordings, account data and private session photographs are not bundled.
