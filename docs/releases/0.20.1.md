# Game immersion toolkit 0.20.1

This maintenance update follows 0.20.0's automatic language repair, clearer
progress, software updater and account settings improvements.

- Update the HTTP client used by the local frontend tools to Undici 7.30.1,
  fixing the reported response-encoding crash, EventSource memory exhaustion
  and integrity-check advisories. Keep the current Cloudflare toolchain instead
  of applying the audit command's proposed downgrade.
- Take PyCryptodome's 3.24.1 security patch while retaining its compatible API.
- Update the Cloudflare Vite integration, Workers types, lint tooling,
  certificate bundle and FastAPI; align the Sherpa wrapper and native core at
  1.13.8 so installation resolves a consistent pair.
- Keep incompatible OpenCV/NumPy and Sherpa major upgrades out of routine
  dependency requests until their native-library migration is validated.

Existing history, game files, accounts and capture settings remain on this PC.
The 0.20.0 software updater can install this verified stable release; older
versions need the documented manual upgrade once.
