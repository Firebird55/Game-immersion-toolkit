# 0.19.0 — One-file mobile libraries and VDO.Ninja Play

Mobile exports now produce one readable game-and-audio-language ZIP containing
the catalog and voices. Conversion stays parallel and resumable. Existing
catalog/voice exports can be wrapped without decoding again, and older split
imports remain supported. ZIP64 outer bundles keep bounded random-access reads
and per-catalog/clip verification. Unchanged exports validate and reuse the
completed bundle without retaining another multi-GB backup; damaged bundles
are repaired from verified cached parts.

The phone opens on Play: open the library, paste the VDO.Ninja viewer link and
tap Start playing. Setup collapses while following subtitles; voice playback is
manual. Settings holds calibration, language/player options, accounts and optional
Paired PC transcript sharing. Browser screen pairing, capture and observation UI
have been removed. The PC transcript channel and its QR/recovery remain supported. Live PC lines
wait for saved history restoration so startup cannot overwrite incoming dialogue.

Import now explains missing catalogs and keeps selected-file and result status
visible after resetting the picker. Reopening asks for the single voice library
file. Failed replacements preserve the working library. Voice audio stays in Files;
it is not duplicated in browser storage.

Synthetic tests cover ZIP64 including Python's below-4-GiB layout, exporter/reader
interoperability, cancellation, malformed archives, retained PC recovery, mobile
zoom and VDO frames through real OCR. The owner's large private ZZZ export was
validated locally without publishing game data. Physical iPhone Files/provider
access and native broadcast endurance remain acceptance checks, not claimed passes.

Compatibility watch found unchanged API documentation/endpoints and changed
public website assets. Settings schema, lookup tabs and language resolution were
reviewed; account and reader regression checks use mocks. The pinned shared package
and its baseline were retained. No account settings were changed.
