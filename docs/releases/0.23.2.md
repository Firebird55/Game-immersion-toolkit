# Game Immersion Toolkit 0.23.2

This follow-up fixes game preparation hanging when a packaged application worker
inherits the API's active shutdown input. Noninteractive preparation now receives
closed input, while explicitly supplied input and owned process cleanup remain
intact. It retains the reader, capture and desktop delivery improvements in the
[0.23.1 release](0.23.1.md).

The local gateway also handles shutdown while a reader's WebSocket is already
closing, so the overlapping close handshake does not fail application exit.

Native release acceptance now requires the actual frozen executable to complete
preparation while the API control reader is active, drain the preparation process
tree, and then accept its independent shutdown command. Source tests alone do not
satisfy this gate. The new acceptance check must pass for each published target;
this note does not claim that a pending candidate has already passed it.

The public Lexirise compatibility review on 2026-11-01 found no required toolkit
adaptation. The [API reference](https://lexirise.app/api-reference) and
[machine-readable reference](https://lexirise.app/llms.txt) retain the public
endpoints, settings values and language capabilities used here. Website changes
affect internal batching, cached reading segments and selection controls; the
removed promotion and build identifiers do not change the integration contract.
