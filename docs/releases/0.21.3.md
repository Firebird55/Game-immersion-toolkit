# Game immersion toolkit 0.21.3

Software updates can now finish while capture is paused, even when transcript
history belongs to another account or a game whose language needs preparation.
Previously, that unrelated history could keep a healthy replacement waiting for
an index it did not need, preventing the update that would repair game data.

The replacement still warms OCR and the frontend before handoff. Active capture
still requires its game index to be ready, and paused capture remains paused.
If capture starts while a paused update is being prepared, the updater keeps
the current runtime active and asks for a retry instead of transferring to an
unprepared game.

The existing Windows update regression in GitHub now covers paused capture with
unrelated history alongside successful live handoff and failed-candidate rollback.
This release includes all 0.21.2 startup, catalog, progress and language-status
fixes. Personal data, account choices and saved language selections are retained.
