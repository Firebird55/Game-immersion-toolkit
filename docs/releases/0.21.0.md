# Game immersion toolkit 0.21.0

This release repairs current game readers, expands dialogue coverage and
simplifies the desktop interface. Visible app branding now uses
**Game immersion toolkit**.

## Clearer setup and accounts

- Prepare a missing game language directly from the transcript. Game browsing
  and detailed language lists stay collapsed until opened.
- Account settings have a compact layout, readable controls and a normal close
  button. Lexirise account controls stay hidden in Migaku mode.
- Update details use the available width. Preparation reports its actual stage,
  distinguishes format errors from missing packs and metadata outages, and
  retries transient failures with backoff. Requests survive restart.
- Fix broken character encoding in the Windows folder picker.

## More dialogue with original voice ownership

- Fix ZZZ's Unity-wrapped catalog and additional typed story/bubble formats.
  Add current-format Knock Knock messages and gameplay tips. Preserve existing
  verified voices while adding newly resolved mappings.
- Fix PRAGMATA extraction that could read unrelated textures. Include omitted
  voice banks and reject unsafe legacy substitution of another performance.
- Resolve Wuthering Waves localization shards that produced placeholders.
  Improve NTE subtitle parsing and retain exact voice provenance.
- Expand Star Rail, Genshin and Endfield narrative imports with separate
  handling for established message, narration, choice and readable formats.
- Include Cyberpunk base-game and Phantom Liberty reading content, and recover
  voices whose exact resource hashes are absent from the path dictionary.
- Read the newer Witcher archive layout and authored choices, journals and
  books. BEYOND and HEAVY RAIN separate explicit silent prompts from spoken
  performances; BEYOND avoids repeatedly validating the same performance.
- Audit all eleven supported games independently. The
  [coverage reports](../game-audits/README.md) document installed-file evidence,
  public sources, supported presentations and remaining gaps.

## Optional unvoiced capture

Enable **Capture setup → Include unvoiced dialogue** to capture confirmed silent
text. It is off by default. Exact matching also covers messages and pages outside
the subtitle crop. Saved silent lines are labeled clearly and can be sent to
Lexirise without an audio upload. Missing or unresolved voices remain separate.

The setting applies to desktop capture across supported readers; some locales
or presentations still have no proven silent records. Paired phones receive
the desktop transcript. Independent offline mobile OCR keeps its existing
voiced catalogs.

Existing data, calibration, credentials, Chinese transcripts and Migaku
preferences are preserved. Automatic verified software updates and binary
packaging for manual GitHub releases remain available. Native file/audio probes
and automated checks do not establish that every chapter, cinematic or physical
capture setup has been played and verified; reports make those limits explicit.
