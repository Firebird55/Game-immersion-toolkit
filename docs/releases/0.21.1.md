# Game immersion toolkit 0.21.1

This patch fixes two issues found while verifying an installed 0.21.0 upgrade.

- Language setup reads the game catalog bundled with the active runtime. An
  upgrade that preserves an older source folder no longer fails to show newly
  supported games, including Rise and Shadow of the Tomb Raider.
- Temporary Windows locks on preparation progress files no longer abort game
  extraction. Progress writes are limited to once per second and resume when
  the file becomes available. Actual extraction and snapshot failures still
  stop preparation and preserve the previous complete table.

Original source files, local transcripts, account credentials and calibration
remain in place. The 0.21.0 game readers and language coverage are unchanged.
