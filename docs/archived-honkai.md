# Honkai Impact 3rd — archived and unsupported

Honkai Impact 3rd support is archived. It is not available in the web UI,
installation wizard, game detection, automatic indexing or new deck provisioning.
Previously configured Honkai capture defaults to automatic selection of supported
games without resetting other capture preferences.

The parser in `backend/honkai_assets.py`, catalog research and offline format
fixtures remain for possible future work. These files do not constitute current
game support. Historical coverage reports in other documents describe older
experiments, not a supported workflow. There is no supported current-story,
Part 2 or newer-chapter capture.

Existing local game files, credentials and captured records are not deleted by
this retirement. Re-enabling the game requires a separately reviewed integration
and complete capture/voice verification.
