# Hito’s World — disabled

Hito’s World is disabled in setup, automatic game detection, capture selection,
index refresh and the mobile game picker. A saved Hito capture preference falls
back to automatic selection of supported games.

Existing transcripts, favorites, local game data and capture calibration remain
on the PC. When saved Hito records exist, **Saved transcript → Archived game history** opens their History and Favorites. Capture and asset refresh remain disabled in this view. The parser and synthetic regression fixtures remain for offline
research and reading existing records.
