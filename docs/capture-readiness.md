# Capture readiness

Run `python scripts/check-capture-readiness.py` from the project with the configured local Python environment. Check native OCR, capture bounds and synthetic English/Chinese text before live gameplay. The test does not require a personal recording.

For live verification, use your installed game and Mandarin voice pack, verify the subtitle crop through Capture setup, and inspect capture phase/error status. Preserve per-PC calibration. Game-specific resolution and OCR checks are documented in ocr-resolutions.md. Keep diagnostic images and logs private.
