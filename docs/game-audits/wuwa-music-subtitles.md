The original `MusicSubtitleManager` follows the event's **source play position**.
`MusicSubtitleView` uses the row's authored appearance/end clocks and separately
renders `LyricsText_<Id>_Original` and `_Translation`. An Original value containing
`{KeepOrigin}` hides that second text label. Matching the resulting Translation
to the literal Original in other UI locales establishes the sung language;
the selected voice pack does not choose or translate a shared song recording.
Each row retains its official translations and any simultaneous original-plus-
translation recognition anchor. Missing or contradictory original text cannot
establish a vocal language.

The capture service enables exact full-frame matching only for the trusted
prepared song presentation. Long lyrics establish an observed stable anchor;
short successors use only the authored preceding row. Menu entry, a changed
scope, stale context and a missing predecessor reset or reject that association.
Ordinary game captions, choices and other games do not gain this song-specific
full-frame permission.

Repeated refrains can share the same complete original source and every official
translation. The index's normal identical-performance coalescing may then return
the first occurrence's ID. An opt-in context rule retains the actual later ID
only after its observed authored predecessor is established and both complete
current source rows agree in every field except identity and already-validated
ordering. This comparison includes the original audio binding, all official
texts, language, player branch, kind, capture channels and OCR anchors; a selected
display model alone cannot establish it. Other visible candidates remain a veto.
Endfield/Genshin's default context behavior is unchanged.

Preparation and later playback share the same snapshot/path-bound original
source cache. Reuse checks both the cached byte binding and RIFF shape. New
revisions and different media paths cannot borrow an older source. Interrupted
new transfers do not replace retained old bytes. Native probe/IO/timeout failure
is an actionable preparation failure rather than an unsupported shape or an
empty replacement for prior contexts. Cache aliases are resolved before adding
nested native work paths, avoiding the confirmed Windows long-path failure.
