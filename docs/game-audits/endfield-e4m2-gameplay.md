# Male and female Sarcophagus movies in the Endfield Beta Test

Reviewed November 13, 2026. The retained female and male `cs_video_e4m2_1` configurations identify a short memory montage in **险途寻棺**, a Valley IV main mission in the January 2025 Beta Test. Two independent Mandarin playthroughs show the different protagonists. Global 1.6.4 still distributes the matching sound effect. ## Original recording and release comparison

The Global 1.6.4 default and slot-0 playables for both protagonists name `au_music_cs_tundra_000_recall_final` and `au_sfx_csv_e4m2_1`. Each has zero caption cues. In the publisher's initial, main and shared hotfix audio packages, exactly one event definition for the effect points directly to media ID **436569754** with zero delay. The original 130,017-byte WEM has SHA-256 `4b43b000aaa3fcbabdd884936169752e366233f352a6fb3ea0f68f12bc5f4a4c` and decodes to 5.983333 seconds. This is the shared sound effect for both movies. The music event did not resolve in the same bank check. [Global 1.6.4 resource index](https://beyond.hg-cdn.com/YDUTE5gscDZ229CW/1.6/resource/Windows/main/11529267-11_hMnwm6yYFPbPuRKr/files/index_main.json) · [Film configuration inventory](endfield-film-configs-1.6.4.csv)

The publisher's Global 1.5.3 packages independently yielded the same single event, media ID, byte length and SHA-256. Both release checks used the launcher resources without a game installation. [Global 1.5.3 resource index](https://beyond.hg-cdn.com/YDUTE5gscDZ229CW/1.5/resource/Windows/main/10731330-8_qaMiws1HojwzPhd6/files/index_main.json)

For each playthrough, decode the WEM and full uploaded audio to 8 kHz mono, apply the same fourth-order 300–3,400 Hz Butterworth band-pass, and search one-second excerpts starting 0.1, 1.1, 2.1, 3.1 and 4.1 seconds into the WEM. The five strongest normalized correlations give the same start time within 1 ms in each playthrough. Repeating this search on the entire 18:15 release walkthrough of **Conference of the Four** gives five different offsets, from 361.20 to 914.26 seconds. Its current mission reads `e4m1d5` and directs the player to rest in the captain's chair. [Release mission](https://github.com/rmxlinux/EndfieldData/blob/d847759f71d4549aba4727b3b0ac1a1ad0e37742/Json/MissionRuntimeAsset/e4m1d5.json) · [Release walkthrough](https://www.youtube.com/watch?v=UpqoxyooKIk)

Two separate retained black-screen text keys, `black_e4m2_1_001` and `black_e4m2_2_001`, describe lying in the Sarcophagus and a continuation notice. Neither has a timed cue in these movie configurations. The exact movie names are absent from all eleven Global release indexes checked. This identifies both historical movies and supports exporting zero spoken sentences from the tested Mandarin montages. A live trigger under another name and the soundtrack of other historical dubs remain unverified.
