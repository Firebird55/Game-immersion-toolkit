# Wuthering Waves language preparation

Supported study locales are English, Japanese, Korean, Simplified Chinese and
Traditional Chinese. Both Chinese scripts use the original Mandarin voice pack.
Only requested ConfigDB text tables are extracted. Official translations are
joined by PlotAudio ID; missing targets remain unavailable.

The installed game's PlotAudio schema and PlotAudioModel playback code define
separate EN/JA/KO/ZH gender flags and external-source prefixes. The reader follows
those fields for the selected dub, retains Rover variants, and excludes dynamic
unresolved filenames and language-independent creature sounds. It never selects
a similarly named source or borrows another dub. Existing official archive,
patch-priority and movie-download checks remain in force.

All five text locales have mocked gender, exact audio path, translation and
missing-pack regressions. An installed English/Mandarin text build mapped 47,300
rows and 46,461 original English voice references. A real installed English voice
was decoded and checked for non-silent output. English and Mandarin packs are
installed here; Japanese/Korean real audio is untested on this host. Synthetic
OCR checks do not establish gameplay chapter or branch coverage.
